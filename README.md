# ⚖️ Legal Workspace (`lex-flow`)

> An open-source, foundational legal workflow, case tracking, and task management system built for lawyers and legal professionals.

---

## 📌 Overview

**Legal Workspace** is a modern, developer-friendly open-source management tool designed to streamline administrative tasks for law firms and independent legal practitioners. This repository provides a core foundation for tracking active legal cases, organizing pending tasks, and managing daily law office operations efficiently.

---

## ✨ Features

### 🟢 Current Release (Core Features)
- **Case & File Tracking:** Organize, edit, and view ongoing legal cases with ease.
- **Task Scheduling:** Assign and track critical deadlines, court hearings, and daily tasks.
- **Modern UI & Responsive Design:** Clean interface built with modern web technologies for desktop and mobile access.

### 🚀 Planned / Upcoming Features
- 👥 **Client Management System:** Comprehensive database and history tracking for individual and corporate clients.
- 💬 **Internal Office Chat:** Secure team communication channel tailored for law firm staff.
- 🤖 **AI Legal Assistant:** Smart document summarization, precedent analysis, and automated drafting features.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** SQLite

---

## 🚀 Getting Started

Follow these steps to run the application locally:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### 2. Installation & Setup
```bash
# Clone the repository
git clone [https://github.com/furkanbaran1/legal-workspace.git](https://github.com/furkanbaran1/legal-workspace.git)

# Navigate into the project directory
cd legal-workspace

# Install dependencies
npm install

# Start the development server
npm run dev
